# This is where I am keeping a step by step of my process

## Step 1: Proof of concept 

 - Supplies used
     - Two RaspberryPi 3A
     - Two 5w charger with switch
     - Two 32GB MicroSD cards
     - Two RaspberryPi cases
     - Breadboard
     - Wire

# Steps to construct #
  
 1. Format MicroSD cards with a headless version of RaspberryOS
 2. Put the MicroSD cards into the Raspberry Pis
 3. Put the Raspberry Pis int the cases
 4. Using a keyboard and monitor set up each Pi with the following
    - connect to network
    - Turn on SSH and I2C
    - Install Git
    - Install Vim
    - Install Screen
 5. Connect the following pins together using the breadboard and wire: 3, 5, and 6


With the following set up I can go ahead and start programming and researching the project.
